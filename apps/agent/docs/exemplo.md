# Base de conhecimento de exemplo

Troque os arquivos desta pasta pelos documentos do seu produto (Markdown ou texto).
Depois rode `npm run ingest` para recarregar a base.

## Horário de atendimento

O atendimento humano funciona de segunda a sexta, das 9h às 18h (horário de Brasília).
Fora desse horário, o assistente responde e abre um chamado para o time.

## Política de reembolso

O cliente pode pedir reembolso em até 7 dias após a compra, sem precisar justificar.
Depois disso, o reembolso é proporcional aos dias não usados do plano.

## Planos

- **Básico:** 1 usuário, 5 GB de armazenamento.
- **Equipe:** até 10 usuários, 100 GB, suporte prioritário.
